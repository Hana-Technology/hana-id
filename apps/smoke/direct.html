Journear Passport smoke test: direct flow

The in-page flow from before the vault: Google (openid only) → POST /v1/sessions → POST /v1/derive → CKD decryption in this page. Kept as the split-flow baseline for the ship gate and for key_index, client choice, revoke and replay tests; the vault page is the main one. Shows public data only: no Google token, CKD secret or private key is ever displayed, logged, stored or sent anywhere but the API.

Google is asked for scope=openid only, in a popup that returns to /direct-callback.html: the chosen Google client must list http://localhost:5173/direct-callback.html as an Authorized redirect URI. The API refuses any token with another claim (400 token_has_pii), and this page doesn't send one.
